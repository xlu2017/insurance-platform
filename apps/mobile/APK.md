# Android APK build and emulator launch

This document records the working Android release build and emulator launch steps for the Insurance Autopilot mobile app.

## Verified artifact

A universal release APK that includes `x86`, `x86_64`, `armeabi-v7a`, and `arm64-v8a` native libraries has been built and run on an Android 35 emulator.

The latest verified build is published as a GitHub Release asset. Download it from
`https://github.com/xlu2017/insurance-platform/releases` (asset: `app-release.apk`),
or build it yourself with the steps below.

## Prerequisites

- Android SDK installed at `$ANDROID_HOME` (or set `ANDROID_HOME` to your own path).
- JDK 17.
- `ANDROID_HOME` and `JAVA_HOME` exported in the shell.
- For emulator hardware acceleration on Linux, `/dev/kvm` must be writable:
  ```bash
  sudo chmod 666 /dev/kvm
  ```

## Build the release APK locally

From the repository root:

```bash
export ANDROID_HOME=/path/to/Android/sdk          # e.g. $HOME/Android/Sdk
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
pnpm install
cd apps/mobile/android
./gradlew :app:assembleRelease
```

The resulting APK is written to:

```
apps/mobile/android/app/build/outputs/apk/release/app-release.apk
```

## Run on an Android emulator

1. Create an Android 35 x86_64 AVD:

   ```bash
   $ANDROID_HOME/cmdline-tools/latest/bin/avdmanager create avd \
     -n test_avd \
     -k "system-images;android-35;google_apis;x86_64" \
     -d pixel --force
   ```

2. Start the emulator:

   ```bash
   $ANDROID_HOME/emulator/emulator -avd test_avd \
     -no-window -no-boot-anim -no-snapshot -no-audio -gpu swiftshader_indirect
   ```

   Omit `-no-window` if you want the emulator GUI.

3. Wait for the device to finish booting:

   ```bash
   $ANDROID_HOME/platform-tools/adb wait-for-device
   $ANDROID_HOME/platform-tools/adb shell 'while [ -z "$(getprop sys.boot_completed)" ]; do sleep 2; done'
   ```

4. Install the APK:

   ```bash
   $ANDROID_HOME/platform-tools/adb install -r \
     apps/mobile/android/app/build/outputs/apk/release/app-release.apk
   ```

5. Launch the app:

   ```bash
   $ANDROID_HOME/platform-tools/adb shell am start \
     -n com.insuranceautopilot.app/.MainActivity
   ```

## What was verified

- App launches to the Welcome screen.
- Bottom tab navigation (Home, Coverage, Autopilot, Documents, Profile) is visible and tappable.
- Coverage screen loads the Assets and Rules sections.
